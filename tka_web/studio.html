RoboMANTAP TKA Studio

Buat, siapkan, validasi, terbitkan, dan bagikan akses TKA kepada siswa.

Akses Studio

Kunci di bawah adalah credential teknis server, bukan password akun Guru dan bukan kode siswa. Karena API saat ini memakai header ini, kunci harus diberikan oleh admin/operator. Setelah disimpan di browser ini, Guru tidak perlu mengetiknya lagi pada setiap langkah.

1. Buat TKA

Isi informasi ujian. Jenjang menentukan jumlah opsi PG: MTs = A–D, MA = A–E.

DRAFT

2. Stimulus

Stimulus adalah bahan pendukung soal: teks, gambar, grafik, tabel, diagram, atau gabungan.

3. Soal

Answer key wajib diisi. Untuk PG, opsi otomatis mengikuti jenjang.

4. Package

TKA memakai 5 package. Setelah soal tersimpan, pilih soal yang masuk ke masing-masing package.

5. Validasi & Terbitkan

Urutan server: DRAFT → REVIEW → VALIDATED → PUBLISHED. Jangan terbitkan sebelum soal dan 5 package lengkap.

Buat Sesi Ujian

Setelah TKA terbit, buat satu sesi. Token sesi ini dibagikan Guru kepada peserta bersama ID Peserta dan Kode Akses.

6. Akses Siswa

Setiap siswa membutuhkan 3 data: Token Sesi (sama untuk satu sesi), ID Peserta, dan Kode Akses Siswa (unik). Berikan ketiganya melalui kartu/daftar akses yang Anda bagikan kepada siswa.

Kartu Akses Siswa

Siswa membuka Portal TKA → pilih “Masuk TKA” → masukkan ketiga data di atas.
